# 官方模拟器与有限次数正式测试

仅在题目有真实接口或 GUI 测试时加载。本技能不授权任何开局；读取用户已有授权和当前 App 状态。没有模拟器时无需建立这套操作流程。

## 授权与预检

分清演练、正式模式及问题编号；命令参数不能替 App 切换模式。不限次数演练也需在用户任务授权内。正式测试有有限机会时，开始前取得明确单局或批次授权；已有批次授权无需逐局重复提问，但不能超出次数或题目范围。

正式前冻结实际源码与配置，验证依赖、身份配置、案例、模式、端口、剩余次数、预算、导出目录和客户端锁。预检结果过期或代码变动且尚未开局时重新预检；已授权开始的当前局不得因静态预检时间到期而盲目重开。持久记录启动意图与状态。

使用可见 UI 和公开接口，不读取隐藏案例或模拟器内部数据。GUI 读取失败只重试读取；不凭不明确结果再点开始。多级确认按同局授权处理，不因慢响应重复启动。

## 单局闭环

1. 确认正确模式与案例，执行授权的启动动作并记录。
2. 等实际数据准备和倒计时结束，确认界面可接入；不能从点击时间机械等几秒认定已就绪，也不用有副作用请求探测就绪。
3. 每局一个客户端，动作串行。响应不确定时按协议复用同一请求及幂等键；不能换新进程或新动作试探。永久未知动作保留锁与原实例，阻止下一局。
4. 实际响应确认后登记动作和额度。达到有效完成条件后正常退出。模型矛盾记错误与未完成；仅在动作已确定且协议允许时安全退出，未知动作不贸然发送退出。
5. 核对界面结果、案例与本地记录。导出先绑定正确历史行，已有文件夹选择器时处理当前选择器，不重复打开。用原生控件按实际标题/标签选择目录，核对导出文件原名、字节和哈希。
6. 按官方要求核对上传状态、剩余次数及归档。单局完整闭环后才开始批次授权中的下一局。

不一致、模式不明、连接永久故障或归档未确认时，保存证据并停止后续局，不猜测成功。全清但导出失败保留为不同状态。有限正式测试不因成绩慢而重抽案例，不同局程序不随意切换。

## 匿名台账

记录匿名 attempt ID、问题/模式、请求时间、确认启动、实际进入、退出、完成条件、清除数、真实总数及来源、各类计时、错误状态、导出哈希与上传/扣次核验。未知字段用 null，并注明原因。

原始 HTTP 日志可能包含身份，放私有/忽略目录。官方要求原样的加密行为日志保留原字节并另行控制访问；不要为了匿名改写其内容。公开统计只含必要匿名字段。
