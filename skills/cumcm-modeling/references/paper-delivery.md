# 论文、科研图表与支撑材料交付

技能维护仓库提供 `latex-template` 原创写作模板及 `skills/examples/prompt-workflow.md` 协作流程；它们不随单个技能目录安装。用户要求使用模板时，从已有仓库或用户指定路径读取；不假定安装副本包含模板。模板的教学数据和证明必须替换为真实题目内容，不把可编译等同于符合当届提交格式。

## 最小且真实的论文同步

先读论文入口、相关章节和现有用户修改，按当轮允许范围编辑。暂停论文时仅维护允许的技术报告；恢复或“最小修改”时只改方法/参数/表格/结论中受本轮影响的内容。不能以一致性为由重写无关章节。

建模推导、已部署算法、测试配置、结果和结论要能沿映射追溯。试验候选未采用不能写入最终算法；未证明最优不能写“最优”。理论限制说明具体缺口，避免笼统套话。

表格直接依据结构化原始数据核对案例编码、字段来源、单位、舍入和聚合公式。缺失值不填0，派生值说明来源。用户要求删列时检查正文引用和表宽，不删原证据字段。

按当前环境支持的编辑器和构建工具编译；独立 LaTeX 文档遵循宿主编辑器要求，多文件工程沿用可用项目构建。确认本次实际成功，不以旧 PDF 冒充。查看受影响页面及必要全篇检查：中文字体、裁切、表宽、引用、重复标签、页码和附录。局部通过不能声称全篇验收。页数和提交格式按当届已核实规则，区分正文与总页数。

## 科研图表

沿用用户明确样式；延续本项目偏好时使用 Matplotlib + SciencePlots，先 `import scienceplots`，再 `plt.style.use(['science', 'no-latex', 'bright'])`，显式选择已安装的中文字体。将样式保留在脚本，不修改全局 matplotlibrc。期刊样式只在需要时使用。

白底、单位与统计口径清晰，重复测量存在时才画有定义的误差范围。导出 PNG，论文需要时加 PDF/SVG；查看最终图和插入论文后的可读性。不能使用 SciencePlots 时如实说明。绘图输出不得以调整坐标或筛样本隐瞒退化。

## 独立支撑材料

建立独立导出目录，包含实际采用的完整源码、依赖版本、配置模板、必要数据/结果、离线复现入口和使用说明；按题目要求单独放原始官方材料。不要整仓库无差别复制或自动覆盖已有提交包。

收集运行依赖闭包；区分采用程序、验证工具和未采纳研究。清单记录文件路径、角色、大小与哈希，避免循环自哈希。附录选必要源码原文，保留来源映射；片段可以省略无关部分，但不能用不可运行简化稿冒充部署程序。运行所需完整代码在支撑目录中。

在隔离解压目录做离线复现：依赖解析、数学验证、统计重算、代表性案例和必要图。不能偷偷从原仓库导入缺失依赖，复现入口默认不触发正式接口、不覆盖归档。核对归档内容而不仅检查打包命令成功。

代码支撑文件按具体题目和用户要求提供，不把匿名处理设为默认竞赛要求，也不因此匿名化 Git 提交。只有官方要求或用户明确要求匿名时，检查代码、配置、文档、PDF 元数据中的身份与个人路径。无论是否匿名，都排除密钥、私有配置、.git、缓存和无关 HTTP 日志；运行队号保持可配置。官方要求原样保留的加密日志不改写。

## AI 工具使用披露

按当届要求及真实记录填写工具名称、可确认的型号/版本、用途与环节、主要提示方式、典型过程、采纳/修改/核验情况。工具品牌不等于具体型号，不从当前模型推断历史型号；无法确认时注明。区分润色与建模/编码/实验贡献，不虚构人工独立核验或 AI 带来的结果。

交付前核对披露与实际工作记录是否一致。用户确认某工具仅润色，就按该范围写，不替其扩充用途。披露文件是否一页、是否匿名及具体格式以用户与官方要求为准。
